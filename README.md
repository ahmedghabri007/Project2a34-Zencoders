# 🚀 Elev8Talent

**Elev8Talent** is a smart matchmaking platform designed to connect ambitious entrepreneurs, talented professionals, and visionary investors. Whether you're launching a startup, expanding your network, or investing in innovation — Elev8Talent helps you find the right match effortlessly.

---

## 🌟 Features

- 🔎 **Profile Discovery**: Explore rich user profiles with bios, interests, locations, and professions.
- 🧠 **AI Chatbot Support**: Smart assistant to answer questions and assist with matchmaking.
- 🧬 **Matchmaking System**: Filter and find profiles based on custom preferences and compatibility.
- 📩 **SMS Notifications**: Stay updated with Twilio-powered SMS alerts.
- 🎙️ **Voice Interaction**: Ask questions using microphone input and get voice replies.
- 🖼️ **Profile Pictures**: Upload and display user images for better engagement.
-  🔐 **Face Recognition Verification**: Secure, AI-based face authentication for a faster, safer trust experience.
- 📊 **Admin Dashboard**: View, update, and manage profiles and match preferences with ease.

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript, Bootstrap  
- **Backend**: PHP  
- **Database**: MySQL  
- **APIs**: Twilio (for SMS, WHATSAPP), Web Speech API (for voice input/output), Mailling 
- **Tools**: XAMPP
